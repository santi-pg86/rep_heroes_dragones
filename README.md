# rep_heroes_dragones
Juego de héroes, dragones y princesas
¡Bienvenido héroe! Debes rescatar a la princesa pasando a través de feroces dragones.
⚔️   : El caballero es un luchador cuerpo a cuerpo. Pasa por encima de un dragón para derrotarlo. Gastas un ataque por cada dragón derrotado.
🏹  : El arquero es un luchador a distancia. Para atacar selecciona el botón de ataque (E). Solo puede atacar en la dirección del último movimiento realizado y únicamente a dos posiciones respecto a la actual. Si el primer movimiento es un ataque se hará hacia la derecha. El ataque se reduce aunque falles el golpe.
🧙  : Contenido bloqueado. Compra el DLC para desbloquearlo.
❤️: Si pasas sobre un corazón recuperas 1 punto de ataque
